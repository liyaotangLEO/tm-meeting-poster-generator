# 海报版式规范

## 画幅与尺寸

| 比例 | 尺寸（像素） | 适用场景 |
|------|------------|---------|
| 3:4（默认） | 1536×2048 | 微信群/取伙等平台宣发，通用竖版海报 |
| 9:16 | 1152×2048 | 短视频封面、手机全屏海报、开屏广告 |
| 1:1 | 2048×2048 | 社交媒体方图、电商主图 |

**默认使用 3:4 竖版**，用户可自行选择其他比例。比例变化时必须重新安排各区域占比和安全边距，不能机械裁切。

---

第一次生图前，必须输出以下版面结构方案跟用户确认：

┌───────────────────────────────────────┐

│              第XXX期例会               │
├───────────────────────────────────────┤
│                                       │
│        会 议 主 题（大字金色）         │  ← 标题区（约13%）
│        今日一词 · XX（副标）           │
│                                       │
├───────────────────────────────────────┤
│                                       │
│                                       │
│      主视觉区（人物/核心意象）         │  ← 主视觉区（约30%）
│        装饰元素环绕分布                │
│                                       │
│                                       │
├───────────────────────────────────────┤
│                                       │
│    信息区（亮点列表 / 工作坊卡片）     │  ← 信息区（约25%）
│                                       │
├───────────────────────────────────────┤
│  时间（快乐黄粗体）                    │
│  地址（白色常规）            [二维码]   │  ← 底部落款区（约19%）
│                        扫码加入我们     │
└───────────────────────────────────────┘

各区域说明：
1. 顶部品牌区：左上角头马logo（规范留白），右侧/居中俱乐部名+期数（快乐黄）
2. 标题区：居中主标题（大字金色/快乐黄），下方副标"今日一词·XX"（白色+快乐黄）
3. 主视觉区：根据视觉元素方案确定，人物/意象居中或偏右，装饰元素环绕
4. 信息区：常规例会放亮点列表，大咖工作坊放工作坊卡片（居中，含标签+题目+讲师身份）
5. 底部落款区：左侧时间地址（时间快乐黄粗体+地址白色），右侧二维码（白色圆角底衬），左右分栏

**⚠️ 输出要求**：第一次生图前必须输出上述 ASCII 示意图格式的版面结构方案，跟用户确认。禁止使用纯像素坐标列表（如"y: 0-180"）作为主要呈现方式，像素坐标仅作为内部参考。

## 各区域详细规范

### 顶部品牌区

- **Logo位置**：左上角，距左边缘约70px，距上边缘约65px
- **Logo尺寸**：约210px宽（等比缩放，高度约174px）
- **Logo留白**：周边留白=字标高度（约logo高度的1/3）
- **俱乐部名+期数**：位于logo右侧或居中，快乐黄色，粗体，约48px字号
- **期数样式**：可加装饰线（如"—— 第444期例会 ——"），快乐黄色

### 标题区

- **主标题**：画面视觉中心，大字，金色/快乐黄渐变，约100-140px字号，粗体
- **主标题位置**：画面上部1/3处，水平居中
- **副标（今日一词）**：主标题下方，约36-44px字号，白色+快乐黄组合
- **副标样式**：可加"今日一词·"前缀，前缀用快乐黄，词语用白色

### 主视觉区

- **占比**：画面中部，约30-40%高度
- **内容**：根据视觉元素方案确定，不预设固定元素
- **人物（如有）**：居中或偏右，半身像，与背景光影融合
- **装饰元素**：围绕主视觉分布，不遮挡文字
- **光影**：与整体色调一致，侧逆光/顶光聚光灯等

### 信息区

#### 常规例会（亮点列表）
- 位置：主视觉区下方，水平居中
- 样式：3个亮点横向排列或纵向列表，每个亮点配图标/序号
- 文字：白色/快乐黄，约32-40px字号

#### 大咖工作坊（工作坊卡片）
- 位置：主视觉区下方，水平居中
- 卡片尺寸：约1070px宽，380px高
- 卡片样式：圆角矩形，金色边框，栗红渐变背景（同色渐变）
- 卡片内容（全部水平居中）：
  1. "大咖工作坊"标签：快乐黄圆角背景+栗红文字，约32px字号
  2. 工作坊题目：白色粗体，约52px字号
  3. 分隔线：快乐黄短线，居中
  4. 讲师姓名+身份：快乐黄，约34px字号，可分两行

### 底部落款区（PIL合成，标准模板）

**左右分栏布局**：

- **左侧区域**（x: 70-1100）：
  - 时间：快乐黄 #F2DF74，粗体，约56px字号，左对齐
  - 地址：白色 #FFFFFF，常规，约40px字号，左对齐，时间下方
  - 时间和地址各占一行，地址不换行（过长时自动缩小字号）

- **右侧区域**（x: 1100-1466）：
  - 二维码：白色圆角底衬（圆角约20px），二维码尺寸约275×275px
  - 二维码位置：右对齐，距右边缘约70px
  - 二维码左侧竖排标签："扫码加入我们"，浅灰色，约22px字号，垂直居中

- **底部背景**：可加半透明栗红渐变条，增强文字可读性

## 安全边距

| 边距 | 3:4 (1536×2048) | 9:16 (1152×2048) | 1:1 (2048×2048) |
|------|-----------------|------------------|-----------------|
| 左右边距 | 70px | 50px | 100px |
| 顶部边距 | 65px | 50px | 80px |
| 底部边距 | 50px | 40px | 60px |

**UI安全区**：底部8%用于放置二维码/落款，禁放与主视觉冲突的元素；左右边缘5%禁放关键信息。

## 文字渲染规范

1. **中文待渲染文字**：用中文双引号 `""` 框定
2. **英文待渲染文字**：用英文双引号 `""` 框定
3. **禁止占位符**：严禁使用 `[文案]`、`XX`、`某某` 等占位符
4. **文字准确性**：日期、时间、地点、人名等关键信息必须与用户提供的完全一致
5. **字体**：统一使用思源黑体 Noto Sans SC（免费商用）
6. **对齐**：标题居中，底部时间地址左对齐，二维码右对齐，工作坊卡片内所有文字居中
