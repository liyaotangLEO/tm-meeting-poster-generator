# AI 生图 Prompt 模板库

## 通用规则

### Prompt 结构（4.5 模型）

按"总览句 → 分区扫描主段落 → 条件收束 → 画幅确认"完成内部方案，再整理成一段连续 Prompt。

1. **总览句**：先说明竖版方向，再前置核心风格、色彩影调和画面类型
2. **分区扫描**：按从上到下、从左到右、从背景到主体的物理空间顺序逐区展开
3. **条件收束**：用 1-2 句收束整体配色、排版、光影和氛围
4. **画幅确认**：内部方案确认目标比例，工具调用时通过 `ratio` 单独传入

### 基础 9 维描述

分区内的每个重要元素必须覆盖：
1. 绝对位置（明确方位、占比、对齐）
2. 元素类型（主体/标题/标签/卡片/装饰）
3. 形态细节（轮廓、组成、姿态、材质）
4. 内容描述（文字逐字写出）
5. 文字视觉样式（字体气质、字号、字重、字色）
6. 状态信息（人物表情、物体状态）
7. 关联关系（对齐、层叠、遮挡、比例）
8. 风格特征（明确视觉风格）
9. 视觉处理工艺（光线、阴影、颗粒、纹理）

### 文字渲染强制规则

- 中文待渲染文字用中文双引号 `""` 框定
- 英文待渲染文字用英文双引号 `""` 框定
- 禁止使用 `XX`、`某某`、`占位符` 等让模型自由补字的表达
- 所有可见文字必须逐字写出
- 品牌名、活动名、人名等专有信息必须逐字保留

### 品牌色强制写入

- **主色（二选一或搭配）**：
  - 栗红 `#772432`（描述为"深栗红色"）—— 温暖、热情、庆典感
  - 忠诚蓝 `#004165`（描述为"深蓝色/忠诚蓝色"）—— 专业、沉稳、理性
  - 两者都是头马主色，**不分主次**，根据当期主题和视觉方案选择
- 强调色：快乐黄 `#F2DF74`（描述为"暖金色/快乐黄色"），仅点缀，不宜大面积
- 渐变只允许同色渐变（如"深栗红到浅栗红的同色渐变"、"深蓝到浅蓝的同色渐变"）
- 禁止跨色渐变（如"红到蓝渐变"）

**主色调选择提示**：在视觉元素方案设计阶段，应跟用户确认本期使用栗红还是忠诚蓝作为主色调，或两者搭配。

### 描述密度

- 营销海报 Prompt 不少于约 1200 字符
- 每个独立元素至少包含一个明确颜色词
- 持续使用绝对方位词和空间衔接词

## 视觉元素方案设计指南

### 设计原则

- **主题驱动**：视觉元素必须与当期会议主题有语义关联
- **发散后收敛**：先发散 3-5 个意象方向，再收敛为 2-3 套完整方案
- **文字先行**：先用文字描述方案，跟用户确认后再转化为图像 Prompt
- **禁止重复**：禁止每期都使用相同的固定元素（如麦克风/声波/信笺）

### 方案结构

每套方案包含：
```
方案名称：[一句话概括]
主视觉意象：[核心画面主体]
装饰元素：[辅助装饰]
光影氛围：[光线方向/明暗对比/情绪基调]
色彩倾向：[在品牌色框架内的变化]
与主题关联：[一句话说明视觉元素如何呼应主题]
```

### 发散方向参考（仅作启发，不预设固定元素）

根据主题关键词，可从以下方向发散：
- **情感类主题**：光、影、信笺、门、窗、镜子、剪影、独白
- **思考类主题**：大脑、灯泡、迷宫、拼图、书籍、笔尖、对话气泡
- **表达类主题**：麦克风、声波、讲台、聚光灯、演讲稿、舞台
- **成长类主题**：种子、阶梯、翅膀、旅程、山峰、日出
- **连接类主题**：桥梁、握手、网络、节点、对话、共鸣

⚠️ 以上仅为发散启发，实际方案必须结合当期主题重新设计，禁止直接套用。

## 模板 A：常规例会海报（image_gen 文生图）

### 使用场景
- 无大咖工作坊的常规例会
- 用户未提供人像素材

### Prompt 结构

```
[总览句] 竖版活动海报，深栗红色主色调，暖金色点缀，[视觉元素方案中的风格词]风格，电影感光影。

[分区扫描 - 顶部品牌区]
画面顶部约占9%区域，左上角放置头马国际演讲会官方彩色logo（圆形地球标+TOASTMASTERS INTERNATIONAL字标），logo周边留白规范。顶部居中位置用暖金色粗体字渲染"[俱乐部名称]"，下方用稍小暖金色字渲染"—— [期数] ——"，两侧带装饰细线。

[分区扫描 - 标题区]
画面上部约占13%区域，水平居中渲染主标题"[会议主题]"，使用大号[字体风格]字体，[颜色描述]，字号约占画面宽度的70%，字重粗体，带有[特效描述]。主标题下方渲染副标"今日一词·[今日一词]"，[颜色描述]，字号约为主标题的1/3，水平居中。

[分区扫描 - 主视觉区]
画面中部约占30-40%区域，[根据视觉元素方案填写主视觉意象描述]。
- 主视觉位置：[绝对位置]
- 形态细节：[轮廓、组成、姿态、材质]
- 装饰元素：[辅助装饰分布]
- 光影：[光线方向、明暗对比]

[分区扫描 - 信息区]
画面中下部约占20-25%区域，[根据亮点列表填写]。
- 样式：[3个亮点横向排列/纵向列表/卡片]
- 每个亮点：[图标/序号 + 文字]
- 文字颜色：[白色/快乐黄]

[分区扫描 - 底部落款区]
画面底部约占15-19%区域，预留左右分栏布局空间（左侧时间地址，右侧二维码），底部背景为[半透明栗红渐变/纯色]。此区域暂不渲染具体文字，留待后期PIL合成。

[条件收束]
整体配色以深栗红 #772432 为主色调，暖金色 #F2DF74 为强调色点缀，白色文字，同色渐变。画面具有[风格词]质感，[光影氛围]，视觉层级清晰，主视觉→大标题→副标→信息→底部落款的阅读引导线明确。

[画幅确认] 目标比例3:4竖版。
```

### 注意事项
- 底部落款区不渲染具体文字，留待 PIL 合成（确保二维码可扫、文字精确）
- 视觉元素部分必须由 Step 3 确认后的方案填入，禁止使用固定模板元素
- 如果亮点列表为空，信息区可简化或合并到主视觉区

## 模板 B：大咖工作坊海报（提供人像，image_edit 图生图）

### 使用场景
- 有大咖工作坊
- 用户提供了大咖人像素材
- 采用左右分栏布局（默认左文字右人像，用户可根据人像构图调换）

### 参考图分层
- `[img0]`：无人像纯净背景（先用 image_gen 生成，包含顶部品牌区、标题区、左侧工作坊信息、底部亮点区和落款区留白）
- `[img1]`：大咖人像素材

### Prompt 结构

```
[编辑目标] 基于 [img0] 的背景海报，将 [img1] 中的大咖人物肖像融入画面主视觉区的右侧，生成一张完整的头马例会宣传海报。采用左右分栏布局，左侧为工作坊信息，右侧为人像。

[保留项]
- 保留 [img0] 的整体色调（深栗红/忠诚蓝主色+快乐黄点缀）、品牌区文字、标题区会议主题大标题
- 保留 [img0] 左侧的工作坊信息卡（大咖工作坊标签、工作坊题目、分隔线、讲师姓名、讲师背景）
- 保留 [img0] 底部亮点区和底部落款区留白
- 保留 [img0] 的构图结构和视觉层级
- 保留 [img1] 中人物的面部特征、发型、服装、姿态

[编辑项]
1. 将 [img1] 中的人物从原背景中分离，融入 [img0] 主视觉区的右侧区域（约占画面宽度58%）
2. 人物位置：主视觉区右侧，水平居中于右侧区域，头部位于标题区下方
3. 人物尺寸：半身像（胸部/腰部以上），高度约占主视觉区的85-90%
4. 人物光影匹配：与背景光线方向一致，可加暖金色轮廓光/光晕效果，增强人物立体感
5. 人物与背景融合：边缘自然羽化，底部渐隐融入背景，无白边、无硬边、无抠图痕迹
6. 人物与左侧文字的关系：人物不遮挡左侧任何文字，左右区域之间有自然的光影过渡
7. 人物姿态：自然大方，禁止手搭在文字区域、禁止多余手指/肢体、禁止手势怪异

[空间线性描述]
从顶部到底部：顶部品牌区保持不变 → 标题区会议主题大标题保持不变 → 主视觉区左右分栏：左侧（约42%宽度）保持工作坊信息卡不变，右侧（约58%宽度）融入大咖人像，人像居中于右侧区域，边缘自然融合 → 亮点区保持不变 → 底部落款区保持留白。

[人物融入约束]
- 人物边缘必须自然融合，禁止白边、硬边、抠图痕迹
- 人物光影必须与背景一致，禁止出现光线方向矛盾
- 人物色调必须与背景协调，禁止出现色温偏差
- 人物禁止遮挡左侧任何文字（工作坊题目、讲师姓名、讲师背景等）
- 禁止出现多余的手、手指、肢体等异常元素
- 人物姿态自然，禁止出现手搭在文字上、手指怪异等情况
- 人物不超出右侧区域边界，不挤压左侧文字空间
```

### 注意事项
- 必须先生成包含左侧工作坊信息的无人像背景 [img0]，再进行人像融合
- 背景 [img0] 的左侧必须已经渲染好工作坊信息（标签、题目、讲师姓名、讲师背景），不要在人像融合阶段再添加
- 如果第一次融合效果不好（人物遮挡文字、边缘不融合、光影不匹配），重新生成而非用 PIL 覆盖
- 人物位置和姿态在 prompt 中必须明确描述
- 默认左文字右人像，如果用户要求调换，在 prompt 中明确说明左右互换
- 讲师背景如果用户提供超过5条，在生成背景 [img0] 时只展示最有分量的3-5条

## 模板 C：大咖工作坊海报（不提供人像，image_gen 文生图）

### 使用场景
- 有大咖工作坊
- 用户选择不提供大咖人像
- 采用左右分栏布局（左侧工作坊信息，右侧抽象视觉元素）

### Prompt 结构

与模板 A（常规例会）基本相同，区别在于主视觉区采用左右分栏：

1. **主视觉区左侧（约42%宽度）—— 工作坊信息卡**：
   - "大咖工作坊"标签：快乐黄圆角背景+深色文字
   - 工作坊题目：白色粗体大字，左对齐
   - 分隔线：快乐黄短线
   - 讲师姓名：快乐黄，粗体
   - 讲师背景：白色小字，2-5行，左对齐
     - 用户提供5个以内：全部展示
     - 用户提供超过5个：提醒用户筛选，展示最有分量的3-5条

2. **主视觉区右侧（约58%宽度）—— 抽象视觉元素**：
   - 用象征性视觉元素代表大咖，如：
     - 讲台+聚光灯
     - 演讲稿+笔尖
     - 奖杯+光环
     - 舞台中央的空麦克风
     - 聚光灯下的剪影
   - 视觉元素居中于右侧区域，与左侧文字有自然的光影过渡
   - 不遮挡左侧任何文字

3. **亮点区**：主视觉区下方，布局灵活（2个→水平并列，3个→水平并列，4个→2x2网格）

### 视觉元素方案特别提示

不提供人像时，视觉元素方案应更注重：
- 右侧用象征性元素传达"大咖"感（聚光灯、舞台、奖杯等）
- 左侧工作坊信息卡是视觉重点之一，文字清晰可读
- 左右区域之间有自然的光影过渡，不生硬分割
- 整体氛围专业、大气，符合工作坊调性

## 生成后检查清单

每次 AI 生图后，必须检查：

1. **文字准确性**：主标题（会议主题）、副标、俱乐部名、期数、工作坊题目、讲师姓名、讲师背景、亮点文字是否完全正确
2. **文字对齐**：
   - 标题区：主标题和副标是否水平居中
   - 大咖工作坊左侧信息卡：所有文字是否左对齐
   - 亮点区：卡片是否整体居中
   - 底部：时间地址是否左对齐，二维码是否右对齐
3. **视觉元素**：是否符合确认后的视觉元素方案
4. **大咖工作坊左右分栏（如适用）**：
   - 左侧工作坊信息是否完整（标签、题目、分隔线、讲师姓名、讲师背景）
   - 右侧人像/视觉元素是否居中于右侧区域
   - 人像是否遮挡左侧文字
   - 左右比例是否合理（左约42%，右约58%）
   - 左右区域之间是否有自然过渡，不生硬
5. **人物（如有）**：是否遮挡文字，边缘是否融合，光影是否匹配，是否有异常肢体（多余手指、手搭文字等）
6. **品牌色**：主色是否为栗红或忠诚蓝，强调色是否为快乐黄，是否有跨色渐变
7. **整体协调性**：各区域比例是否合理，视觉层级是否清晰，左右是否平衡
8. **底部留白**：底部落款区是否有足够空间留给 PIL 合成（时间地址+二维码）

**如果检查不通过**：
- 优先重新生成（调整 prompt），而非用 PIL 覆盖
- 只有底部文字、logo、二维码必须用 PIL 合成
- 工作坊信息卡文字如果不清晰或不完整，优先重新生成，PIL 覆盖容易因渐变背景产生色差
