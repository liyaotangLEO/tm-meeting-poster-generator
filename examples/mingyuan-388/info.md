## 视觉元素方案

- **主视觉意象**：James Wang 半身人像（居中，融入背景）
- **装饰元素**：聚光灯、演讲稿、笔尖、暖光光斑

## 制作流程（含踩坑记录）

1. 需求收集与确认（大咖工作坊 + 提供人像）
2. 品牌规范预检
3. 视觉元素方案 + 版面结构方案确认
4. image_gen 生成无人像纯净背景
5. image_edit 图生图融合人像（[img0]=背景，[img1]=人像）
   - **踩坑1**：人像过小，放在中间挡住字，与背景不融合 → 改用 image_edit 参考图融合
   - **踩坑2**：手搭在工作坊卡片上，手指怪异 → prompt 中明确双臂交叉，禁止手搭卡片
   - **踩坑3**：人物遮挡副标"开口" → 调整人物位置，最终去掉今日一词
   - **踩坑4**：人物偏右 → 调整为居中
   - **踩坑5**：工作坊卡片文字不居中 → 重新生成（PIL 覆盖因渐变背景有色差）
6. PIL 合成（logo + 底部时间地址 + 二维码）
7. 品牌合规检查 + 交付

## 关键经验

- 人像融合必须用 image_edit 图生图，不能用 PIL 抠图硬贴
- 人物位置和姿态在 prompt 中必须明确描述
- 卡片文字不居中优先重新生成，PIL 覆盖容易因渐变背景产生色差
- 每次修改后必须检查整体协调性，不能只改单点
