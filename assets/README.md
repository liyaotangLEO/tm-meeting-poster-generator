# 素材目录

本目录存放 Skill 内置的品牌素材。

## logo/

### toastmasters-logo-color.png

- **说明**：头马国际演讲会官方彩色 logo（球标 + 字标）
- **来源**：头马官方品牌素材库
- **用途**：海报左上角品牌区，PIL 合成时自动贴入
- **使用规范**：
  - 彩色原版，禁止变形、变色、加特效
  - 最小尺寸 72px（2cm）
  - 周边留白 = 字标高度（约 logo 高度的 1/3）
  - 禁止放在非头马标准色背景上
  - 禁止与其他 logo 一同摆放

## 用户需自行提供的素材

以下素材不包含在 Skill 中，需用户在使用时提供：

1. **VPM 微信二维码**（必填）— 清晰可扫，建议 ≥500×500px
2. **大咖人像素材**（可选）— 大咖工作坊模式下用户自选，不提供时用抽象视觉元素
